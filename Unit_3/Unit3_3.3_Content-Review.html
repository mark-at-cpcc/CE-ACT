Technical Overview

This section walks through the core concepts for Unit 3 before you hit the full chapter reading in 3.4: network cables and connectors, common network hardware, IPv4/IPv6 addressing fundamentals, ports and protocols, internet connection and network types, and the tools that go with all of it.

In Plain Terms

Think of this section as the trailer, not the movie. It gives you the shape of the week so the full reading in 3.4 has something to attach to, instead of hitting you cold.

UTP vs. STP

Unshielded twisted pair (UTP) is standard office/home cabling. Shielded twisted pair (STP) adds a foil or braided shield around the conductors to resist electrical interference — common near heavy machinery, elevator shafts, or long outdoor/direct-burial runs.

Plenum-Rated Cable

Cable jacketed with a fire-retardant, low-smoke material required by building code any time cable runs through a plenum space — the area above a drop ceiling or below a raised floor used for HVAC airflow.

T568A and T568B Wiring Standards

Both standards define the same eight-conductor color order, just with the green and orange pairs swapped:

  • T568A: White/Green, Green, White/Orange, Blue, White/Blue, Orange, White/Brown, Brown
  • T568B: White/Orange, Orange, White/Green, Blue, White/Blue, Green, White/Brown, Brown

A cable wired to the same standard on both ends is a straight-through cable, used for connecting dissimilar devices (computer to switch). A cable wired to T568A on one end and T568B on the other is a crossover cable, historically used to connect similar devices directly (switch to switch). Most modern NICs auto-detect and correct for this (Auto-MDIX), but the wiring standard itself is still fair game on the exam.

Memory Trick

Both standards share the same middle four wires (blue pair, white/blue pair) — only the green and orange pairs trade places between the outer positions. If you can remember one standard's color order, you already know the other: just swap green and orange.

Copper Connectors

RJ11 — telephone line connections (4 or 6 conductor). RJ45 — standard Ethernet networking (8 conductor). F-connector — coaxial cable, used for cable internet and cable TV. Punchdown block — a fixed termination point where individual twisted-pair wires are pressed (punched down) into slotted contacts, commonly found on patch panels and 66/110 blocks in a wiring closet.

Power over Ethernet (PoE)

A standard that delivers electrical power to a device — commonly an access point, IP camera, or VoIP phone — over the same twisted-pair cable that carries its network data, eliminating the need for a separate power outlet at the device.

One Box, Many Devices

A typical home "router" is usually a router, switch, access point, modem, and basic firewall combined into a single unit. On the exam and in the field, be ready to identify each function separately even when they live in one physical box.

IP Addressing Fundamentals

IPv4

A 32-bit address written as four decimal numbers (octets) separated by periods, e.g. 192.168.1.10. The available address space is exhausted at the public internet level, which is part of why IPv6 exists.

IPv6

A 128-bit address written as eight groups of hexadecimal digits separated by colons, e.g. 2001:0db8:85a3:0000:0000:8a2e:0370:7334. The vastly larger address space removes the scarcity problem that drives IPv4 workarounds like NAT.

The Five Classes of IPv4 Addresses

Before CIDR (Classless Inter-Domain Routing) became the modern standard, every IPv4 address belonged to one of five classes, determined by the value of the first octet. You'll still see class boundaries referenced constantly — especially because the private address ranges live inside them — so it's worth knowing all five, even though only Classes A, B, and C are the ones that actually matter day to day. Class D is reserved for multicast traffic and Class E is reserved for experimental use; neither is assigned to devices on a network.

Common Exam Trap

127 falls inside the Class A numeric range, but the entire 127.0.0.0/8 block is reserved for loopback addresses (127.0.0.1 is "localhost") and is never assigned to a real host. The usable Class A range for host addressing is effectively 1–126.

Each of the three usable classes sets aside its own private address block. Here's how the private ranges you'll be tested on map back to the classes they come from:

Why This Still Matters

Real-world networks today use CIDR and variable-length subnet masks instead of rigid class boundaries, so you'll rarely hear someone say "that's a Class C network" in the field. But the class system is still the fastest way to recognize a private address on sight, and it explains why 172's private block is oddly narrow (172.16–172.31 only, not the full 172.0–172.255 Class B range) and why 192.168.0.0/16 is really 256 Class C–sized networks bundled together rather than one native Class B block.

Common Exam Trap

The 172 private range only covers 172.16.0.0 through 172.31.255.255. An address like 172.32.x.x or 172.10.x.x looks private at a glance but is actually a public address — check the second octet carefully.

APIPA (Automatic Private IP Addressing)

When a device is configured for DHCP but cannot reach a DHCP server, Windows assigns itself an address in the 169.254.0.0/16 range so it can still communicate on the local segment. Seeing a 169.254.x.x address on a device is a strong sign that DHCP is unreachable.

Static vs. Dynamic Addressing

Static addressing means a technician manually assigns and fixes an IP address on a device — common for servers, printers, and network hardware that other devices need to find at a predictable address. Dynamic addressing means a DHCP server assigns the address automatically, typically for lease renewal after a set period — the default for most client devices.

Ports & Protocols

TCP vs. UDP

TCP is connection-oriented and reliable — it establishes a connection first and confirms delivery, at the cost of some overhead. UDP is connectionless and fast — it sends data without confirming delivery, favoring speed over reliability. Streaming and VoIP often use UDP; file transfers and web pages typically use TCP.

Memorizing Ports

Group them by what they do rather than memorizing a flat list: file access (20/21 FTP, 445 SMB), remote access (22 SSH, 23 Telnet, 3389 RDP), email (25 SMTP, 110 POP3, 143 IMAP), and name/address services (53 DNS, 67/68 DHCP). The groupings make recall faster under exam pressure.

Match the Tool to the Task

A cable that's already built but not working needs a cable tester. A cable with no connector on the end needs a crimper. A cable that's lost in a bundle behind a wall needs a tone generator and probe. Keeping the tool tied to the specific failure or task — rather than memorizing a flat list — is what the exam actually tests.
