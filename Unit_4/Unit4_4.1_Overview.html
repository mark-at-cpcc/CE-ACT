Technical Overview

Unit 4 continues Domain 2.0 (Networking) and adds a dedicated block of Domain 5.0 (Hardware and Network Troubleshooting). You will explain virtual networking concepts, identify the services that keep a network running, compare wireless networking technologies, install and configure a SOHO network, and troubleshoot common network problems.

In Plain Terms

Last week was about the physical network — cables, hardware, and addresses. This week is about what runs on top of that network: the services that hand out addresses and resolve names, the wireless technologies that cut the cable entirely, and the small-office/home-office setups you'll be configuring for real people. By Thursday you should be able to walk into a SOHO network, recognize what services it depends on, and troubleshoot it when something breaks.

Learning Objectives

By the end of Unit 4, you will be able to:

  1. Explain virtual networking concepts, including VLANs and VPNs, and describe how each is used to segment or protect network traffic.
  2. Identify common network services — DNS, DHCP, file and print sharing, mail, web, proxy, and load balancing — and describe the role each plays.
  3. Compare wireless networking technologies, including 802.11 frequencies and channels, Bluetooth, RFID, and NFC.
  4. Explain wireless security concepts and describe how to install and configure a SOHO network, including basic router and firewall settings.
  5. Identify and resolve common network problems, including lack of connectivity, intermittent wireless connections, high latency, and high jitter.
  6. Apply a consistent troubleshooting methodology to a realistic network problem scenario.

Where This Fits on the Exam

Domain 2.0 (Networking) is 23% of the 220-1201 exam, and this week finishes out the domain with services, wireless, and SOHO configuration. Domain 5.0 (Hardware and Network Troubleshooting) is 28% of the exam — the single largest domain — and this is the first week it gets a dedicated block of its own, on top of the Ticket of the Day habit that has been running since Unit 1.
