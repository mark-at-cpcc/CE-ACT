Domain 1 — Networking Concepts

OSI — Open Systems Interconnection

The seven-layer reference model that divides network communication into Physical, Data Link, Network, Transport, Session, Presentation, and Application.

On the job: A technician who says "no link light, that is Layer 1" is using the OSI model to decide what to check first.

Learn more: Video · Plain definition (TechTerms) · Reference

PDU — Protocol Data Unit

The unit of data at a given layer: bits at Layer 1, frames at 2, packets at 3, segments or datagrams at 4.

On the job: A capture tool that says "frame 42" is showing you the Layer 2 PDU that carried a packet.

Learn more: Video · Plain definition (TechTerms) · Reference

MAC — Media Access Control

The 48-bit hardware address burned into every network interface, written in hexadecimal; the Layer 2 address.

On the job: A switch's MAC address table tells you which port a device is plugged into.

Learn more: Video · Plain definition (TechTerms) · Reference

NIC — Network Interface Card

The hardware (card or on-board chip) that connects a device to a network and holds its MAC address.

On the job: "Media disconnected" in ipconfig means the NIC has no link.

Learn more: Video · Plain definition (TechTerms) · Reference

LAN — Local Area Network

A network within one building or site under one organization's control.

On the job: Your office floor, switched and wired, is a LAN.

Learn more: Video · Plain definition (TechTerms) · Reference

WAN — Wide Area Network

A network spanning cities, regions, or countries, usually over a provider's circuits.

On the job: The link from the office to the data center across the state is a WAN.

Learn more: Video · Plain definition (TechTerms) · Reference

MAN — Metropolitan Area Network

A network spanning a city or metro area, larger than a LAN and smaller than a WAN.

On the job: A hospital system with sites across one city connected by fiber runs a MAN.

Learn more: Video · Plain definition (TechTerms) · Reference

PAN — Personal Area Network

A network of one person's devices within a few meters, typically Bluetooth or USB.

On the job: A phone, a smartwatch, and earbuds form a PAN.

Learn more: Video · Plain definition (TechTerms) · Reference

WLAN — Wireless Local Area Network

A LAN carried over 802.11 wireless.

On the job: The Wi-Fi in a coffee shop is a WLAN.

Learn more: Video · Plain definition (TechTerms) · Reference

SAN — Storage Area Network

A dedicated network that carries block-level storage traffic between servers and storage arrays.

On the job: Virtualization hosts reach their disks over a SAN so storage traffic never competes with user traffic.

Learn more: Video · Plain definition (TechTerms) · Reference

TCP — Transmission Control Protocol

The connection-oriented Layer 4 protocol that guarantees ordered, acknowledged delivery.

On the job: Web, email, and file transfer ride on TCP because a lost byte matters.

Learn more: Video · Plain definition (TechTerms) · Reference

UDP — User Datagram Protocol

The connectionless Layer 4 protocol with no acknowledgments; fast and lightweight.

On the job: Voice, video, and DNS use UDP because speed matters more than a retransmitted packet.

Learn more: Video · Plain definition (TechTerms) · Reference

IP — Internet Protocol

The Layer 3 protocol that addresses and routes packets between networks.

On the job: Every device on your LAN has an IP address assigned by DHCP or by hand.

Learn more: Video · Plain definition (TechTerms) · Reference

ICMP — Internet Control Message Protocol

The Layer 3 protocol that carries error and diagnostic messages, including the echo used by ping.

On the job: When ping says "Destination host unreachable," that is an ICMP message.

Learn more: Video · Plain definition (TechTerms) · Reference

ARP — Address Resolution Protocol

The protocol that maps an IP address to a MAC address on the local network.

On the job: arp -a on a workstation shows which MAC the default gateway answered with.

Learn more: Video · Plain definition (TechTerms) · Reference

DHCP — Dynamic Host Configuration Protocol

The service that automatically assigns IP addresses, masks, gateways, and DNS servers to hosts.

On the job: A workstation with a 169.254 address did not get a DHCP lease.

Learn more: Video · Plain definition (TechTerms) · Reference

DNS — Domain Name System

The service that resolves names such as www.example.com to IP addresses.

On the job: "The internet is down but I can ping 8.8.8.8" is almost always a DNS problem.

Learn more: Video · Plain definition (TechTerms) · Reference

HTTP — Hypertext Transfer Protocol

The protocol web browsers and servers use to exchange pages, on TCP port 80.

On the job: A site that loads over HTTP shows no padlock because nothing is encrypted.

Learn more: Video · Plain definition (TechTerms) · Reference

HTTPS — Hypertext Transfer Protocol Secure

HTTP carried inside TLS encryption, on TCP port 443.

On the job: A firewall that blocks port 443 breaks nearly every website.

Learn more: Video · Plain definition (TechTerms) · Reference

SSH — Secure Shell

An encrypted remote command-line protocol on TCP port 22, used to manage network devices.

On the job: A technician configures a switch over SSH instead of unencrypted Telnet.

Learn more: Video · Plain definition (TechTerms) · Reference

SMTP — Simple Mail Transfer Protocol

The protocol for sending email between mail servers and from clients, on TCP port 25 (587 with submission).

On the job: When outbound mail queues up, the first check is whether port 25 or 587 is reachable.

Learn more: Video · Plain definition (TechTerms) · Reference

IMAP — Internet Message Access Protocol

The protocol for reading mail that stays on the server, on TCP port 143 (993 with TLS).

On the job: A phone and a laptop seeing the same inbox are both using IMAP.

Learn more: Video · Plain definition (TechTerms) · Reference

TLS — Transport Layer Security

The encryption protocol that secures HTTPS and many other services; the successor to SSL.

On the job: An expired TLS certificate produces the browser's "your connection is not private" warning.

Learn more: Video · Plain definition (TechTerms) · Reference

UTP — Unshielded Twisted Pair

Copper cable with four twisted pairs and no shielding; the standard LAN cable.

On the job: Cat 6 UTP runs from the patch panel to every desk.

Learn more: Video · Plain definition (TechTerms) · Reference

SFP — Small Form-factor Pluggable

A hot-swappable 1 Gbps transceiver module that lets a port use fiber or copper.

On the job: Swapping a 1000BASE-SX SFP for a 1000BASE-LX SFP changes the port from multimode to single-mode.

Learn more: Video · Plain definition (TechTerms) · Reference

QSFP — Quad Small Form-factor Pluggable

A four-lane transceiver form factor: QSFP+ carries 40 Gbps and QSFP28 carries 100 Gbps.

On the job: Spine switches in a data center are full of QSFP28 modules.

Learn more: Video · Plain definition (TechTerms) · Reference

SMF — Single-Mode Fiber

Fiber with a 9-micron core and a laser source, for runs of kilometers.

On the job: Buildings across a campus are joined with SMF and LR transceivers.

Learn more: Video · Plain definition (TechTerms) · Reference

MMF — Multimode Fiber

Fiber with a 50- or 62.5-micron core and an LED or VCSEL source, for runs of hundreds of meters.

On the job: A 10 Gbps link between two racks in one room is MMF with SR transceivers.

Learn more: Video · Plain definition (TechTerms) · Reference

DAC — Direct Attach Copper

A short twinaxial cable with transceivers permanently attached to each end.

On the job: Two switches in one rack are linked with a one-meter 10 Gbps DAC.

Learn more: Video · Plain definition (TechTerms) · Reference

CIDR — Classless Inter-Domain Routing

The notation and method that expresses a subnet mask as a prefix length, such as /24.

On the job: 192.168.10.0/26 tells you the mask is 255.255.255.192 without looking it up.

Learn more: Video · Plain definition (TechTerms) · Reference

Domain 2 — Network Implementation

VLAN — Virtual Local Area Network

A logical segmentation of a switch into separate broadcast domains.

On the job: Printers on VLAN 20 cannot see guest Wi-Fi on VLAN 30 unless a router allows it.

Learn more: Video · Plain definition (TechTerms) · Reference

STP — Spanning Tree Protocol

The Layer 2 protocol that blocks redundant switch links to prevent loops.

On the job: A looped patch cable that takes down a floor is what STP exists to prevent.

Learn more: Video · Plain definition (TechTerms) · Reference

RSTP — Rapid Spanning Tree Protocol

The faster successor to STP (802.1w) that converges in seconds instead of up to a minute.

On the job: After a switch reboot, RSTP brings ports back far faster than legacy STP.

Learn more: Video · Plain definition (TechTerms) · Reference

FHRP — First Hop Redundancy Protocol

A family of protocols that let two routers share one virtual gateway address so hosts keep a default gateway when one router fails.

On the job: Hosts point at the virtual address; if the primary router dies, the standby answers.

Learn more: Video · Plain definition (TechTerms) · Reference

VRRP — Virtual Router Redundancy Protocol

The open-standard FHRP that elects a master router for a virtual IP.

On the job: Two firewalls from different vendors share a gateway address with VRRP.

Learn more: Video · Plain definition (TechTerms) · Reference

OSPF — Open Shortest Path First

A link-state interior routing protocol that computes the best path by cost.

On the job: Every router in the company learns every subnet through OSPF without anyone typing static routes.

Learn more: Video · Plain definition (TechTerms) · Reference

BGP — Border Gateway Protocol

The path-vector routing protocol that connects autonomous systems across the internet.

On the job: An organization with two internet providers runs BGP so traffic survives one provider's outage.

Learn more: Video · Plain definition (TechTerms) · Reference

RIP — Routing Information Protocol

A distance-vector routing protocol using hop count, limited to 15 hops.

On the job: RIP still appears on the exam and on small legacy networks; it is rarely deployed new.

Learn more: Video · Plain definition (TechTerms) · Reference

NAT — Network Address Translation

Rewriting private IP addresses to a public address at the network edge.

On the job: A whole office reaches the internet through one public address because the router does NAT.

Learn more: Video · Plain definition (TechTerms) · Reference

PAT — Port Address Translation

NAT that maps many private addresses to one public address by tracking port numbers.

On the job: Home routers do PAT; that is why hundreds of devices can share one public IP.

Learn more: Video · Plain definition (TechTerms) · Reference

PoE — Power over Ethernet

Delivering DC power to a device over the same Ethernet cable that carries data (802.3af/at/bt).

On the job: Access points and IP phones are powered by PoE switches, so no outlet is needed at the ceiling.

Learn more: Video · Plain definition (TechTerms) · Reference

LACP — Link Aggregation Control Protocol

The protocol that bundles several physical links into one logical link for bandwidth and redundancy.

On the job: Two 10 Gbps uplinks are bundled with LACP so the server sees one 20 Gbps connection.

Learn more: Video · Plain definition (TechTerms) · Reference

MTU — Maximum Transmission Unit

The largest frame or packet size an interface will send, 1500 bytes on standard Ethernet.

On the job: A VPN tunnel that drops large downloads often has an MTU mismatch.

Learn more: Video · Plain definition (TechTerms) · Reference

SSID — Service Set Identifier

The name of a wireless network that clients see and join.

On the job: Hiding the SSID does not secure a network; it only stops it from appearing in the list.

Learn more: Video · Plain definition (TechTerms) · Reference

BSSID — Basic Service Set Identifier

The MAC address of an individual access point radio serving an SSID.

On the job: A site survey tool lists each BSSID so you can tell which AP a client is attached to.

Learn more: Video · Plain definition (TechTerms) · Reference

WPA — Wi-Fi Protected Access

The family of wireless security standards; WPA3 is current, WPA2 is common, WPA and WEP are obsolete.

On the job: A new network should be configured for WPA3, falling back to WPA2 only for old clients.

Learn more: Video · Plain definition (TechTerms) · Reference

AP — Access Point

The device that bridges wireless clients to the wired network.

On the job: A dead spot on the third floor usually means an AP is missing or misplaced.

Learn more: Video · Plain definition (TechTerms) · Reference

WLC — Wireless LAN Controller

A device or service that centrally manages many access points.

On the job: Changing the guest password on the WLC pushes it to forty APs at once.

Learn more: Video · Plain definition (TechTerms) · Reference

MDF — Main Distribution Frame

The building's primary wiring closet, where the provider's circuit enters and the core equipment lives.

On the job: The demarc, the core switches, and the fiber to every IDF are in the MDF.

Learn more: Video · Plain definition (TechTerms) · Reference

IDF — Intermediate Distribution Frame

A secondary wiring closet on a floor or wing, fed from the MDF.

On the job: Every desk on the third floor is patched to the third-floor IDF.

SNMP — Simple Network Management Protocol

NMS — Network Management System

The software that monitors, alerts on, and manages network devices.

NTP — Network Time Protocol

The protocol that synchronizes device clocks, on UDP port 123.

PTP — Precision Time Protocol

A time protocol more precise than NTP, used where microseconds matter.

RTO — Recovery Time Objective

Domain 5 — Network Troubleshooting

CRC — Cyclic Redundancy Check

The error-detection value in a frame's trailer; a CRC error means the frame arrived corrupted.

On the job: Rising CRC errors on one port point to a bad cable or a duplex mismatch.

Learn more: Video · Plain definition (TechTerms) · Reference

APIPA — Automatic Private IP Addressing

The 169.254.0.0/16 address a host assigns itself when DHCP does not answer.

On the job: A workstation showing 169.254.x.x cannot reach the DHCP server.

Learn more: Video · Plain definition (TechTerms) · Reference

TTL — Time To Live

A counter in each packet decremented by every router; the packet is dropped at zero.

On the job: traceroute works by sending packets with increasing TTL values.

Learn more: Video · Plain definition (TechTerms) · Reference

LLDP — Link Layer Discovery Protocol

A vendor-neutral protocol by which devices announce their identity to directly connected neighbors.

On the job: show lldp neighbors tells you which switch port an access point is on.

Learn more: Video · Plain definition (TechTerms) · Reference

CDP — Cisco Discovery Protocol

Cisco's proprietary neighbor-discovery protocol, equivalent to LLDP.

On the job: show cdp neighbors reveals the switch at the other end of an uplink.

Learn more: Video · Plain definition (TechTerms) · Reference

TDR — Time-Domain Reflectometer

A tool that sends a pulse down a copper cable and measures the reflection to find breaks and their distance.

On the job: The TDR reported an open at 47 meters, right where the cable passed a ceiling fan.

OTDR — Optical Time-Domain Reflectometer

QoS — Quality of Service
