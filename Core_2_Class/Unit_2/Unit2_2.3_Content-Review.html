How to Use This Page

This review covers the same ground as your Sybex reading, but shorter and in plain language. It does not replace the reading — the exam draws on detail this page does not carry. Use it to build the mental map first, then read the chapters to fill it in. Better still, keep a Windows computer open beside this page and open each tool as you read about it.

Three Ways Into Windows

In Unit 1 you learned what Windows is. Now you learn to operate it. A technician reaches into Windows in three ways, and the exam expects you to know all three:

  • Built-in tools — Task Manager, the Microsoft Management Console snap-ins, and utilities such as System Information. These show you what the computer is doing and what went wrong.
  • Settings screens — Control Panel and the Settings app. This is where you change how Windows behaves.
  • The command line — where you type an instruction and get an answer immediately. It is often the fastest route, and sometimes the only one.
In Plain Terms

Think of a car mechanic. The dashboard gauges show what is happening right now — that is Task Manager. The service history in the glove box shows what happened last week — that is Event Viewer. The adjustment knobs change how the car drives — that is Control Panel and Settings. And the diagnostic scanner plugged in under the steering wheel gives fast, exact answers to specific questions — that is the command line. A good mechanic uses all of them, and so will you.

Task Manager

Task Manager shows what the computer is doing right now. It is usually the first tool you open on a "my computer is slow" or "a program froze" ticket. Open it with Ctrl+Shift+Esc, by right-clicking the Start button, or from the Ctrl+Alt+Del screen.

TabWhat It ShowsWhen You Use It
ProcessesEvery running app and background process, with its current CPU, memory, disk, and network useFinding the program that is slowing the machine down, and ending a frozen app with End task
PerformanceLive graphs of CPU, memory, disk, network, and GPU use, plus hardware details such as installed RAM and CPU speedDeciding whether a slow computer is short on memory, overloaded, or waiting on a busy disk
StartupPrograms that launch automatically when the user signs in, with their impact on startup timeSpeeding up a slow sign-in by disabling programs that do not need to start automatically
UsersEveryone signed in to the computer and the resources each is usingSeeing which account is running a heavy process on a shared machine
ServicesBackground services, whether each is running or stopped, and its process IDChecking whether a service a program depends on — such as the print spooler — is running, and starting or stopping it

Windows 11 moved these tabs into a menu down the left side of the window, and calls the Startup tab Startup apps. The information in each one is the same.

The Slow-Computer Ticket

A user says, "My computer is crawling." Open Task Manager, go to Processes, and click the CPU column heading to sort by use. Then do the same for Memory. Most of the time, one program sits at the top using far more than anything else. Now you have a real progress note: which process, how much, and what you did about it.

One caution: End task closes a program without saving. Ask the user before you end anything that might hold unsaved work.

The Microsoft Management Console (MMC)

Microsoft Management Console (MMC)

A Windows framework, started with mmc.exe, that hosts administrative tools called snap-ins. Each snap-in can also be opened on its own by running its .msc file. A technician can build a custom console that holds several snap-ins together and save it for reuse.

You can open any snap-in by typing its file name into the Start menu search or the Run box (Windows key + R). The exam lists each one with its file name, so learn them in pairs.

Snap-inRunWhat It DoesA Ticket It Solves
Event Viewereventvwr.mscShows the logs Windows keeps — chiefly Application, Security, and System — with each entry marked as Information, Warning, Error, or Critical"My computer restarted by itself last night." The System log shows what happened just before.
Disk Managementdiskmgmt.mscShows every drive and partition, and lets you create, format, resize, and assign letters to volumes"I installed a second drive and it doesn't show up." (See Disk Management, below.)
Task Schedulertaskschd.mscRuns a program or script automatically at a set time or when an event happensScheduling a nightly backup script, or finding the scheduled task that launches a pop-up every morning
Device Managerdevmgmt.mscLists every hardware device and its driver; lets you update, roll back, disable, or uninstall a driver"My new webcam doesn't work." A warning icon beside it points to a driver problem.
Certificate Managercertmgr.mscShows the digital certificates stored for the current user — the credentials that prove a website, person, or device is who it claims to beChecking whether a certificate a company app needs is installed or has expired
Local Users and Groupslusrmgr.mscCreates and manages user accounts and groups that exist only on this computer. Not available in Home editions.Adding a local account for a new employee on a workgroup computer, or resetting a local password
Performance Monitorperfmon.mscRecords performance data over hours or days so you can review it later, not just watch it live"It gets slow every afternoon, but never while you're here." Record through the afternoon and read the results.
Group Policy Editorgpedit.mscSets local policies that control what users can and cannot do on this computer. Not available in Home editions.Blocking USB storage on a kiosk computer, or setting a screen-lock timeout
Connect It to Core 1

You used Device Manager in Core 1 whenever a new card or peripheral needed a driver. The tool is the same; the question is different. In Core 1 the question was "Is the hardware installed?" In Core 2 it is "Is Windows talking to the hardware correctly?" A device that worked yesterday and fails after an update is a classic case for Roll Back Driver.

Now, Over Time, or in Detail?

Three tools show performance, and the exam will make you choose. Task Manager shows what is happening now, at a glance. Resource Monitor shows what is happening now in detail — which files a process has open and which network connections it is using. Performance Monitor shows what happened over time. Match the question's time frame to the tool.

These tools are not MMC snap-ins, but they sit beside them in every technician's toolkit. Each opens by running its program name.

A Real Example You Will Meet on the Job

A technician checks Safe boot in System Configuration to troubleshoot a problem, fixes it, and forgets to uncheck the box. From then on, the computer starts in Safe Mode every single time — no network drivers, low resolution, a very confused user. When you turn on Safe boot in msconfig, write "uncheck Safe boot" in your ticket notes before you restart.

The Windows Registry

Windows Registry

A central, hierarchical database where Windows stores configuration settings for the operating system, hardware, installed applications, and each user profile. Settings are organized as keys, subkeys, and values under a small number of root keys.

Most settings you change in Control Panel or Settings are really stored in the Registry. Those screens are the safe way to change it. Registry Editor is the direct way, with no safety checks.

Root KeyWhat It Holds
HKEY_LOCAL_MACHINE (HKLM)Settings for the computer as a whole — hardware, drivers, installed software, and system configuration
HKEY_CURRENT_USER (HKCU)Settings for the user who is signed in right now — desktop, preferences, and per-user app settings
HKEY_USERS (HKU)Settings for every user profile loaded on the computer
HKEY_CLASSES_ROOT (HKCR)File associations — which program opens which type of file
HKEY_CURRENT_CONFIG (HKCC)The hardware profile the computer started with
Back Up Before You Touch It

Registry Editor has no undo button, and most changes take effect the moment you make them, with no warning. A wrong change can stop an application from starting, or stop Windows from starting at all. Before any edit, export the key you are about to change (File > Export) or create a restore point. For this course, look around the Registry as much as you like, and change nothing.

In Plain Terms

The Registry is Windows' filing cabinet of settings. Control Panel and Settings are the receptionist who files things for you correctly. Registry Editor lets you walk into the file room yourself. That is sometimes necessary — but you photocopy the folder before you change anything in it.

Disk Management

Disk Management (diskmgmt.msc) is the graphical tool for preparing drives. It shows every physical disk, how it is divided into partitions, and the file system and drive letter of each volume. With it you can:

  • Initialize a new disk, choosing the MBR or GPT partition style you learned in Unit 1
  • Create a new volume in unallocated space and format it with a file system such as NTFS or exFAT
  • Assign or change a drive letter
  • Extend a volume into free space next to it, or shrink a volume to make room for another
  • Delete a volume — which destroys everything on it

"I Installed a Second Drive and It Doesn't Show Up"

This is one of the most common storage tickets. A brand-new drive does not appear in File Explorer because it has no partition and no file system yet. Open Disk Management. Windows usually asks to initialize the disk — choose GPT for a modern system. Then right-click the unallocated space, choose New Simple Volume, pick a size, a drive letter, and a file system, and finish. The drive appears in File Explorer.

Connect It to Unit 1

Every choice in that wizard is something you already studied. MBR or GPT? Unit 1, partitioning. NTFS, exFAT, or FAT32? Unit 1, file systems. Disk Management is where those decisions stop being definitions and become clicks.

The Windows Command Line

The command line is a text window where you type a command and press Enter. In Windows you reach it through Command Prompt (cmd.exe), Windows Terminal, or PowerShell; every command in this unit works in all three. Some commands — sfc, diskpart, and chkdsk with repair options, for example — need an administrator window: right-click Command Prompt or Terminal and choose Run as administrator.

In Plain Terms

Why type when you can click? Three reasons. It is faster — one line replaces six windows. It shows detail the graphical tools hide. And it can be repeated — a command you type once can be saved in a script and run on a hundred computers, which is exactly where Unit 3's scripting lesson picks up.

The Most Important Command Is /?

Type any command followed by /? — for example, ipconfig /? — and Windows lists every option that command accepts, with a short explanation of each. Nobody memorizes every switch. Technicians look them up in seconds, and so can you. CompTIA lists [command name] /? as an objective in its own right.

A Real Example You Will Meet on the Job

"My S: drive disappeared." Type net use to see what is mapped. If S: is missing or marked Unavailable, you can map it again: net use S: \\fileserver\shared. If the command fails, ping fileserver tells you whether the server can be reached at all. Two commands, and you know whether the problem is the mapping or the network.

Commands That Destroy Data

format, diskpart clean, rmdir /s, and robocopy /mir all delete data without asking twice. Run them only in NETLAB, or on a lab drive you have emptied. Every other command on this page only reads information and is safe to try on your own computer.

Windows Settings: Control Panel and the Settings App

Windows has two places to change settings. Control Panel is the older one, and it is still full of tools technicians use every day. The Settings app is the newer one, and Microsoft moves more into it with each release — in Windows 11, several Control Panel items simply open a Settings page. The exam tests both, so learn where things live in each.

File Explorer Options

  • View hidden files — shows files and folders marked hidden, such as the AppData folder in each user profile.
  • Hide extensions for known file types — on by default, so report.docx shows as just report.
  • General options — where File Explorer opens, single-click or double-click, and privacy settings for recent files.
  • View options — the advanced list that includes the two settings above and many more.
Why Technicians Turn Extensions On

With extensions hidden, a file named invoice.pdf.exe appears as invoice.pdf — a program pretending to be a document. That is a favorite trick in phishing emails, which you study in Unit 4. Showing extensions is one of the first changes many technicians make on a new machine.

Power Options

SettingWhat It Means
Power plansPreset groups of power settings, such as Balanced and Power saver, that trade performance against battery life
Sleep/suspendKeeps the work in memory and powers down almost everything else. Wakes in seconds, but still uses a little power.
StandbyAnother name for the low-power sleep state; you will see both words in documentation
HibernateSaves the contents of memory to the drive and powers off completely. Uses no power, and resumes where you left off, more slowly than sleep.

Shut Down Is Not Always a Fresh Start

With fast startup on, Shut down saves part of the system to the drive instead of closing everything. That is why "turn it off and back on" sometimes fixes nothing. Restart always performs a full restart. When a ticket calls for a clean start, choose Restart. And when a USB device keeps disconnecting on a laptop, USB selective suspend is worth checking.

Where Does It Live?

Many tasks can be done in either place, and scenario questions love that. Uninstalling a program: Programs and Features or Settings > Apps. Changing the default printer: Devices and Printers or Settings > Devices. Allowing an app through the firewall: Windows Defender Firewall in Control Panel. Checking for updates: Settings > Update and Security. Keep a two-column list as you read — Section 2.4 shows you how.
