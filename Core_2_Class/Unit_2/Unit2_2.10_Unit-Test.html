Test Format

Each attempt draws 20 items from a 100-item pool covering this unit's objectives — Windows features and tools, command-line tools, and Windows settings — weighted to mirror how they're represented on the actual 220-1202 exam. Answer choices are reshuffled every attempt. Click an answer to select it, then click Grade My Answers to see your results.

Test Taking Skills

In order to successfully pass the CompTIA exam you should read each question and each answer. Select the best answer that you think is correct. Then read the question again, and each answer. If you agree with the original answer move on; otherwise, "work through" the answers and see which ones are easily dismissable.

Full understanding requires completion of all 20 items and a review of any missed questions before moving on — not a specific score. Take the time to understand why an answer was wrong before you close this page.
