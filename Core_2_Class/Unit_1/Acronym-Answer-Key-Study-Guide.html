A Note on How to Use This as an Adult Learner

The blank worksheet was intentionally structured for you to do the work yourself — that struggle is what builds recall. This document is different. It's a reference, and how you use a reference is up to you.

You already have real experience with technology, even if you don't think of it that way. You've set up a Wi-Fi router, plugged in a monitor, or watched a phone lose signal in a basement. That's not incidental — it's the raw material this document is built to connect to. As you read each entry, pause on the real-world example and ask yourself: where have I already seen this? Adults retain technical vocabulary far better when it attaches to a memory they already have than when it's memorized cold. Don't just read this top to bottom in one sitting. Pull it up when a term comes up in lecture, in a lab, or in a practice question you got wrong — that's the moment it will actually stick.
